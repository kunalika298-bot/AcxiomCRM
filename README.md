AcxiomCRM

AcxiomCRM is a Customer Relationship Management web application developed as a university project.

It is used to manage customers, leads, opportunities, follow-ups and activities in one place.

Features

- User registration and login
- Role-based access
- Customer management
- Lead management
- Lead conversion
- Opportunity management
- Follow-up management
- Activity tracking
- Dashboard and reports
- Audit logs
- REST API

Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML
- CSS
- Bootstrap
- JavaScript
- Chart.js

About

This project was developed as part of my university project to build a practical CRM application using ASP.NET Core and SQL Server.
